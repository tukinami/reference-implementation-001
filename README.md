# 参考実装 001

## どういうものか

制作中のゲームに対する参考実装です。
「当たり判定をどう扱うか」を比較するためのものです。

- 制作環境にそのまま移植できるものではありません(TypeScript + Web技術で手動作成)
- 実装自体にはAI不使用です。
- 採用は任意です。
- 動きを見てロジックを確認するためのものです。
- キー入力処理に難があります。(半角英数字入力になっていないと受け付けない、など)
- アニメーション・UIはほとんどオミットされています。
